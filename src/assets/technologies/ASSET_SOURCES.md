# Technology icon sources

The technology SVGs in this directory are bundled locally; the application does not request logos at runtime.

## Clearly identified fallbacks

Simple Icons v16.38.1 did not provide current entries for Memcached, Amazon Web Services, Microsoft Azure, Cloudflare R2, FAISS, or pgvector. The corresponding files are compact typographic fallback marks, not claimed to be official logos. AWS, Azure, and Cloudflare R2 use familiar product text/colors for identification; Memcached, FAISS, and pgvector use neutral text marks. Replace these files with approved official assets if project-specific brand permission is obtained.
